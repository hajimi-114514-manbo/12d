# 伪L2D 骨架工作室 V1.0

**把分层画作按图层名自动生成可动画的伪L2D骨架，带窗体界面。**

语义规范采用 **Adobe Character Animator 官方图层命名规范**（行业事实标准），
所以输出的 PSD 既能被 Character Animator 全自动绑定，也能被 Live2D Cubism Editor 自动转成部件。

## 一键拆分（SeeThrough）

把一张角色图**一键拆成 17 层并自动建骨架**，无需手工准备分层素材。

**入口（二选一）：**
- 点底部工具栏的 **「拆分图片」**按钮，弹出文件选择框（支持 `png / jpg / jpeg / webp / bmp / tif / tiff`）
- 或**直接把图片拖进预览画布**。拖入时画布会高亮成蓝灰色（`#1f2a3a`），松手即开始拆分。
  依赖 `tkinterdnd2`（导入名 `TkinterDnD`），已装；若该库缺失，程序会退化为「仅按钮选图」而不报错。

**自动流程：**
1. 确保 ComfyUI 在跑——不在就自动拉起，约 **50 秒**就绪
2. 提交 SeeThrough 工作流并轮询（分辨率 1024，约 **15 分钟/张**）
3. 自动收集 17 层 PNG + `layers_meta.json` 到输出目录
4. 自动建骨架并载入界面（图层列表、节点表、预览同步刷新），弹窗提示成功

**输出目录：** `D:\视频\26114\seethrough_out\<图片名>\`
（含 `layers_meta.json`、`layer_<名>.png`、`layer_<名>_depth.png`、`seethrough_preview.png`）

**细节：**
- 拆分在后台线程执行，界面不卡死；进度条实时显示 ComfyUI 状态与收集进度
- 任务进行中按钮自动禁用，防重复触发
- 失败时弹窗显示原因，进度条清空

**⚠️ 输入图建议：白底 / 纯色底效果最好。**
SeeThrough 会把背景误当部件，带复杂背景的图容易拆出碎片层。建议先把角色抠到纯色背景上再拆分。

## 骨架结构

以爱音（17 层 SeeThrough 输出）为例，自动生成 6 个节点：

| 节点 | 父节点 | 支点算法 | 包含层 |
|---|---|---|---|
| `body` | root | 包围盒底边中心 | topwear, neck |
| `head` | body | 与 body 的**接触点** | face, nose, mouth, ears-* |
| `hair_back` | head | 与 head 的**接触点** | back hair |
| `hair_front` | head | 与 head 的**接触点** | front hair |
| `eye_left` | head | 包围盒中心 | eyewhite-l, irides-l, eyelash-l, eyebrow-l |
| `eye_right` | head | 包围盒中心 | 右侧四层 |

**支点定位是核心**：
- 「连接型」层（头发贴头皮）取该层 alpha 中**距父层 alpha 最近的像素** —— 距离变换求 argmin，正好落在发根
- 「叠放型」层（眼睛组）取各层 alpha 并集的**包围盒中心**
- 这两种区分由 `PIVOT_MODE` 控制，可改

## 动画

内置 4 类行为（`animation_for`）：
- `body` 呼吸（Y 位移正弦）
- `head` 头部轻摆 + 跟随呼吸
- `hair_front` / `hair_back` 摆动，相位错开 0.7 让前后发不同步
- `eye_left` / `eye_right` 眨眼（4.6s 周期，闭合到 6%）

改振幅/频率直接改 `animation_for`。

| 保存预览 | `preview_tXX.png` | 当前帧存图 |

## 限制

1. **静态平面层**：只能旋转/位移/缩放，做不了网格形变（SeeThrough 不输出 mesh）
2. **SeeThrough 是生成式分解**：层拼回与原画在细节上有差异（发丝、边缘等），不是无损切分
3. **输入图背景要干净**：SeeThrough 会把复杂背景误当部件，白底/纯色底效果最好
4. **命名契约**：映射表只认 CA 规范名；输入图层叫 `layer_03.png` 之类会落进 `other` 节点
5. **支点是启发式**：接触点算法对"自然连接"的层很准，对"叠在上面"的层可能给错位置，需在界面里手动拖
