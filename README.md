# 木偶工作室（Muppet Studio）

> **伪L2D 骨架工作室 v2.4.0** —— 把动漫立绘自动拆成分层骨架并做动画的 PySide6 桌面应用。
>
> 当前版本：v2.4.0（单一版本源见 `l2d_rig_qt.py` 的 `VERSION` 常量，窗口标题引用它；每次小更新 patch+1，成体系大功能 minor+1）。
>
> 语义规范采用 **Adobe Character Animator（CA）官方图层命名规范**，所以导出的 PSD 既能被
> Character Animator 全自动绑定，也能被 Live2D Cubism Editor 自动转成部件。

---

## 启动

双击 **`木偶工作室.exe`**（无黑窗，异常时弹窗并写 launcher.log）

也可命令行直接跑：

或命令行（工作目录设为 `D:\work\puppet\muppet_studio`）：

```
D:\Python312\python.exe l2d_rig_qt.py
```

- 启动后为**空白工作台**（不自动载入工程）；可从菜单「最近打开」、把图片拖入画布拆分，或载入应用自带的示例工程 `示例工程\`
- 界面为深色主题，左侧有「工作台」导航栏（可用标题栏最左的折叠按钮收起/展开）
- 需要 **NVIDIA GPU**：本地拆分引擎走 CUDA，显存峰值约 **3.3GB**（nf4 量化）

## 界面操作

### 标题栏

从左到右：

- **折叠按钮**（侧栏面板图标，白色线条）：显示/隐藏最左侧的导航栏
- **文件**下拉：新建 / 打开工程 / 最近打开（子菜单，最多 5 个）/ 导入 PSD / 拆分图片（SeeThrough）/ 保存 / 另存为
  - **新建**：弹窗输入**工程名** + 画布宽高（见下节「工程与导航栏」）
  - **打开工程**：选择含 `layers_meta.json` 的文件夹载入（如自带 `示例工程\`，或拆分输出目录）
  - **最近打开**：hover 向右展开最近 5 个工程，点击直接载入；目录失效自动过滤
  - **拆分图片（SeeThrough）**：选图走 SeeThrough 拆分（见「双引擎拆分」）
- **编辑**下拉：撤销 / 重做
- **导出**功能已并入「文件」菜单（导出 PSD / AE 脚本 / JSON / MP4 / GIF）

### 布局与可拖宽

工作区为**左右两栏**，中间用 1px 分隔条隔开，**拖动分隔条即可改变宽度**（默认约 5:3，画布在左）。

- **左侧：画布 + 播放**（占约 3/5）
- **右侧：上下分割**（占约 2/5）——上为**骨架节点表**、下为**图层列表**，中间的分隔条也可拖
- 最左导航栏**默认隐藏**；点标题栏最左的侧栏面板图标按钮可唤出（140px，显示**工程列表**与拆分进度百分比），再点收起，空间自动让给内容区

### 工程与导航栏

- **新建即建工程**：文件 → 新建弹窗顶部输入**工程名**（默认 `工程`，重名自动 `_2/_3`），再填画布宽高（默认 1024×1024，1..8192）。确认后立即在 `projects\<工程名>\` 建目录、写占位 `rig_project.json`（含 `name/width/height`）+ 空 `layers_meta.json`，并**立刻建好空画布 rig**（拖图即可用），同时在导航栏新增该工程项。
- **工程名校验**：留空不允许关闭弹窗（顶部提示）；名字会去掉 `\/:*?"<>|` 与首尾空格，截断 60 字符。
- **导航栏工程列表**：新建成功、载入工程成功、另存为成功都会把工程加进导航栏；**同目录只显示一项**（文字自动更新）。启动时自动扫描 `projects\` 把已有工程列出。**点导航项即载入该工程**。
- **已去掉「工作台」按钮**：导航栏不再有工作台项，只有工程列表；内容区始终是画布工作台，不受影响。
- **保存 / 另存为**：保存写 `rig_project.json`（含 `name` 字段）+ 拷贝图层 PNG；另存为弹窗**默认填当前工程名**、可改，落到 `projects\<新名>\`，并同步导航栏文字。

### 左侧：画布 + 播放

- **预览画布**：红圈是支点，黄字是节点名，**按住支点直接拖动即可调位**
- **棋盘格背景**：图像区域内铺 PS 风格深浅灰棋盘格，**透明区域露棋盘格**（表示背景透明），不是黑底
- 空白时画布上有提示文字：把图片拖进来开始，或点「拆分图片」
- **播放 / 暂停**：内置动画（呼吸、头部摆动、头发摆动、眨眼）
- **时间滑块**：拖动可逐帧预览（播放时自动同步）
- **拆分图片**（主按钮）：弹出文件选择框选图开始拆分
- **本地引擎**复选框（默认勾选）：勾选 = 用进程内本地引擎；取消勾选 = 直接走 ComfyUI
- 下方进度文字：显示拆分 / 导出进度

### 画布缩放（Photoshop 风格）

预览画布支持 Photoshop 风格的缩放与平移：

| 操作 | 效果 |
|---|---|
| `Ctrl+0` | 适合窗口 |
| `Ctrl+1` | 实际像素（100%） |
| `Ctrl+=` | 放大一级（×2） |
| `Ctrl+-` | 缩小一级（÷2） |
| `Ctrl+滚轮` | 以光标位置为锚点缩放（光标下的图像像素不移动；每格约 1.25 倍） |

- 缩放范围 **2%~1600%**
- 平移：**空格 + 左键拖拽**，或 **鼠标中键拖拽**（只移动画面，不改缩放倍率）
- 画布**左下角角标**显示当前倍率：适合窗口模式显示「适合窗口 N%」，手动模式显示「N%」

> **注意**：预览画布用的是**半分辨率 LOD 渲染**（0.5×，为提速），所以「实际像素 100%」指的是 **LOD 图的 100%**（相对原图约 50%）。导出的 PSD / MP4 仍是**全分辨率**，GIF 为半分辨率直出，都不受预览缩放影响。

> **透明背景**：引擎新增 `render_frame_rgba`（RGBA 输出，背景 alpha=0）；`render_frame` 保留为兼容接口（黑底合成，签名加了 `bg` 参数）。画布在图像区铺棋盘格透出透明区域，GIF 导出保留透明；MP4 等视频格式不支持透明，仍为黑底。

### 右侧：骨架节点表 + 图层列表（上下分割）

- **上半：骨架节点表**，列：节点 / 父 / 支点 / 层数；**双击「支点」单元格可微调该支点**
- **下半：图层列表**
  - 从上到下 = 从最前到最后（顶层在最上面）
  - **拖动图层可重排叠放顺序**
  - **双击图层切换显隐**（● 显示 / ○ 隐藏）
  - **右键图层**：置顶 / 删除（删除可 Ctrl+Z 撤销）
  - 底部按钮 **「显示/隐藏全部」** 一键切换所有图层

### 拖图入画布

直接把图片文件拖进预览画布即可触发拆分（支持 `png / jpg / jpeg / webp / bmp / tif / tiff`）。

## 双引擎拆分

界面提供两种 SeeThrough 拆分引擎，**输出格式完全相同**
（`layers_meta.json` + `layer_<名>.png` + `layer_<名>_depth.png` + `seethrough_preview.png`）。

### 本地引擎（默认，勾选「本地引擎」）

- 进程内直接调用随附的 `see-through\` 核心库，**不需要 ComfyUI**
- 模型用 nf4 量化权重，**显存峰值约 3.3GB**，单张约 **14 分钟**
- **失败自动回退**：本地引擎报错时会自动改用 ComfyUI 引擎重试

### ComfyUI 引擎（取消勾选「本地引擎」）

- 通过 HTTP 提交到 `http://127.0.0.1:8188` 的 ComfyUI
- 启动时若 ComfyUI 不在跑，会自动拉起（约 **50 秒**就绪），随后提交工作流并轮询
- 单张约 **15 分钟**（1024 分辨率）
- 只用标准库 + numpy + Pillow，无额外 Python 依赖，但需要 ComfyUI 环境

### 拆分成功后

- 输出目录：`D:\视频\26114\seethrough_out\<图片名>\`
- 自动载入新图层并建骨架（图层列表、节点表、预览同步刷新），弹窗提示成功
- 拆分在后台线程执行，界面不卡死；任务进行中「拆分图片」按钮自动禁用，防重复触发
- 失败时弹窗显示原因

## 菜单功能

### 撤销 / 重做（Ctrl+Z / Ctrl+Y）

快照式历史栈（最多 60 步），记录图层顺序、叠放顺序和各节点支点。

### 新建

弹窗输入**工程名** + 画布宽高。确认后创建 `projects\<工程名>\` 工程目录（重名自动 `_2/_3`），写占位 `rig_project.json` + 空 `layers_meta.json`，立即建好空画布 rig，并在导航栏新增该工程项（详见「工程与导航栏」）。

### 导入 PSD

支持 `*.psd / *.psb`：

- **CA 标签名和 SeeThrough 原始层名都认**：先过 `CA_TAG` 归一化，再查 `TAG_DEPTH`；配饰类（handwear / eyewear / wings…）走 `RAW_DEPTH`
- **空层自动剔除**：不含有效像素（alpha 阈值内的像素少于 64 个）的层直接跳过
- **叠放顺序按语义深度表自动排**：不依赖 PSD 图层序，避免顺序错乱
- 递归进入 PSD 分组（SeeThrough 导出的 Head / Mouth 组），跳过不可见图层
- 导入后自动建骨架并载入

### 保存 / 另存为

- **保存**：写 `rig_project.json`（含 `name` 字段、宽高、draw_order、节点、支点）并把各图层 PNG 复制到当前工程目录，同步导航栏文字
- **另存为**：弹窗默认填当前工程名（可改），落到 `projects\<新名>\` 后同样写出，并同步导航栏文字

## 导出格式

| 格式 | 产物 | 说明 |
|---|---|---|
| PSD | `rig_character.psd` | 按 CA 分组结构导出（`Body` 组 / `Head` 组 / `Head→Mouth` 子组），标签含 `+` 前缀（=可独立形变）。可丢进 Character Animator 全自动绑定，或 Live2D Cubism 自动转部件 |
| AE 脚本 | `rig_build.jsx` | 生成 AE 工程：节点预合成 + 父子嵌套 + 动画表达式 |
| JSON | `rig_spec.json` | 自研骨架描述，供任意播放器读取 |
| MP4 | `rig_anim.mp4` | 10 秒 / 30fps 动画视频，**黑底合成**（视频格式不支持透明）；cv2 写 mp4v，写不了时回退到 Vocal2Midi 自带的 `ffmpeg.exe` 合成 |
| GIF | `rig_anim.gif` | 15fps 动图，**透明背景**（255 色量化 + 索引 255 专属透明 + disposal=2），半分辨率直出 + 全局调色板（体积更小） |

导出弹窗默认保存在当前工程目录。MP4 / GIF 在后台线程渲染，进度实时显示，不阻塞界面。

## 已知限制

1. **SeeThrough 是生成式分解**：拆出的层拼回后与原画在细节上有差异（发丝、边缘等），不是无损切分
2. **输入图背景要干净**：SeeThrough 会把复杂背景误当部件，白底 / 纯色底效果最好；复杂背景容易拆出碎片层
3. **静态平面层，无网格形变**：每层只能旋转 / 位移 / 缩放，做不了 mesh 形变（SeeThrough 不输出网格）
4. **眨眼是压扁近似**：眼睛/眼睑通过纵向缩放（支点在框底）模拟闭合，不是逐像素的眼皮形变
