## 1. 现状锚点

- `proj = {type, version:1, width, height, fps, tracks[], dialogue[]}`：单时间轴；
  同轨 clip 不重叠（拒绝式）、MIN_DUR/EPS 约定、sanitize 全容错。
- 导出（`webgal_export.export_game`）：单 `game/scene/start.txt` + 规则 1-9
  语句映射 + 规则 10 台词/H2a 切换行 + 规则 11 playable 运行时树拷贝；config.txt
  `Game_key/Title_img/Title_bgm`。
- 导入（`webgal_import.import_script`）：单脚本 → 单时间轴；`choose/branch/label/
  jumpLabel/callScene/changeScene/setVar/unlockCg/unlockBgm/setTextbox` 全部
  **跳过 + 警告**（`_UNSUPPORTED`），往返丢分支——本设计要闭合的核心缺口。
- F1 剧情编辑器：dialogue 表格（t/who/text/dur 行编辑 + 撤销 + seek 联动）。
- 撤销模型 = 全 proj 快照（`push_history`），天然覆盖未来任何结构扩展。

## 2. 工程模型扩展（①）

### 2.1 为什么是"幕列表"而不是另两条路

| 方案 | 语义 | 致命点 |
|---|---|---|
| 幕=一条长时间轴的分段容器 | 幕共用全局 t 轴 | 分支后各幕**并行存在于同一轴**：播放头跨幕跳转时 t 语义崩（每幕时长独立、总时长无意义）；不重叠/trim/吸附要在分段约束下重写；全部既有断言失效 |
| 分支=全局节点图（非线性编辑器重造） | 幕=图节点、边=选项 | 引擎、UI、时间轴面板三者全部重造；收益只服务 3-5% 的可视性需求（WebGAL 运行时才是执行器） |
| **A1 幕列表（选定）** | 每幕自带完整单时间轴 | 现有全部机制（轨道/clip/台词/导出规则/合成/撤销）**按幕原样复用**；分支只是幕对象上的几个新字段 + 幕间引用边。成本集中在迁移与多文件导出，都是薄层 |

### 2.2 结构（v2）

```jsonc
proj = {
  "type": PROJECT_TYPE, "version": 2,
  "width": …, "height": …, "fps": …,          // 画布参数上移全局（幕间共享）
  "vars": [ {"name": "affinity", "default": 0} ],
  "acts": [
    {
      "aid": "a1", "name": "幕一·入学",
      "tracks": [ …现有结构原样… ],
      "dialogue": [ …现有结构原样（含 H2a motion/expression）… ],
      "choices": [
        { "cid": "c1", "t": null,              // null=幕尾；数值=幕中分支（预留）
          "prompt": "要不要搭话？",             // 可选旁白行（导出为台词行）
          "options": [
            { "text": "搭话",  "target": "a2",  // aid 或悬空原名（导入保真用）
              "set":  ["met=true"],             // 副作用→伪幕 setVar
              "when": null },                   // 可见条件→-when 透传
            { "text": "走开",  "target": "a3", "set": [], "when": "met==false" }
          ] }
      ],
      "jumps": [ { "t": 12.5, "when": "met==true", "target": "a4" } ],
      "next": null                              // 无分支续幕（导出 changeScene 衔接）
    }
  ]
}
```

约束：`aid` 工程内唯一；`target/next` 引用悬空 → sanitize 清引用 + 记警告（容错
风格与现有一致，绝不抛）；choice 数/每 choice 选项数上限（建议 8/6，防导出文件
爆炸）；`t=null` 归一化为该幕时长。

### 2.3 兼容与投影（关键机制）

- **读**：`sanitize_project` 遇 `version<=1`：把顶层 tracks/dialogue 包成
  `acts=[{aid:"a1", name:"默认幕", …}]`，choices/jumps/next 空。内存中永远是
  v2 形态；**保存写 `version:2`**（旧文件仍可读）。
- **`act_view(proj, aid) -> dict`**：返回与旧 proj **同形状**的投影
  `{type,width,height,fps,tracks,dialogue}`。`video_export.compose_frame`、
  快照、时长计算、StageView、时间轴面板**全部只吃 act_view，签名零改动**。
- 工作台会话态：`wb._aid` 当前幕；切幕 = `_aid` 改 + `render_frame(0)`。
- 撤销：快照全 proj，天然含跨幕改动，无需扩。
- 回归锚（验收级）：单幕空 choices 工程 → 导出**逐字节等于现状**、
  `webgal_export_test` 全量绿、旧工程文件载入保存往返结构等价。

## 3. 导出映射（②）

### 3.1 多幕 → 多文件

- `acts[i]` → `game/scene/<safe_name(aid 或显示名)>.txt`（重名 `_2`，复用
  `_NamePool`）；**首幕同时写 `start.txt`**（WebGAL 固定入口=start.txt，保持
  现状语义），其余幕文件由跳转语句引用。
- 幕内语句生成 = 现有规则 1-10 逐幕执行（各幕独立时间游标；同刻顺序/事件
  排序约定不感知幕）。
- stats 新增 `scenes: n`；playable（规则 11）不变——运行时树一份，多 scene
  天然可玩。
- config.txt 不动（入口恒 start.txt）。

### 3.2 分支语句落法（全部标准语法，伪幕技术）

| 载体 | 导出行（示意，语法按 §8 核对） |
|---|---|
| choice 基础 | 幕尾/幕中 t 处：`choose:搭话:a2_scene|走开:a3_scene;` |
| option.set 副作用 | 带 set 的选项 target 改指**生成的伪幕** `<aid>__ch<k>_o<m>.txt`：内容 = 若干 `setVar:…;` 行 + `changeScene:<真实目标>;`。零方言、组合任意 |
| option.when | choose 选项 `-when` 条件（透传字符串）；不支持时降级伪幕内 `if:` + 兜底目标（§8-3 未证实，L2 首日核） |
| jumps | 事件流 t 处插 `if:cond:target_scene;`（§8 实测语法；t=幕尾则并入结尾顺序） |
| next | 幕文件末行 `changeScene:<next_scene>;`（无 choice/next 的幕保持现状收尾） |
| vars 初始化 | **仅 start.txt 头部** `setVar:name=default;` 一节（伪幕/各幕文件不重复声明，避免播放中重置——变量作用域核对 §8-4） |
| prompt | choice.t 前一行台词 `旁白:prompt;`（可选） |

导出顺序稳定性：伪幕文件名由 `(aid,cid,option_index)` 纯函数决定 → 同工程两次
导出逐字节一致（回归可断言）。

## 4. 导入升级（③）

### 4.1 新入口

`import_project_dir(game_scene_dir, entry="start.txt")` → `(ok, msg, proj)`：
从入口 BFS 收集被引用 scene 文件（choose/changeScene/if/callScene 目标），
**每文件一幕**；visited 防环；单文件 `import_script` 行为不变（=单幕）。

### 4.2 可行子集与回折叠

| 脚本语句 | 落地 |
|---|---|
| `choose:t1:s1|t2:s2;` | choices 节点（t=游标当前值，即幕尾或语句序位）；目标 scene 名 → 对应幕 aid（BFS 内已知）或**悬空原名**（target 字段保原名 + 警告，往返不丢） |
| `setVar:x=1;`（独立行） | 顶层 vars 声明 + 伪幕折叠：若所在文件仅含 setVar*+changeScene 且由 choose 指来 → **吸收回 option.set，不生成为幕**（往返闭环的关键） |
| `if:cond:scene;`（单条件，**实测语法，jumpIf 不存在**） | jumps[{t=游标, when=cond, target}] |
| `changeScene:x;` 幕尾 | next=x |
| `callScene:x;` | 按 next/choice 近似 + 警告"返回语义不支持"（A4 放弃项） |
| 选项 `-when` | option.when 透传原字符串 |

### 4.3 明确放弃（维持现状"跳过+警告"，不新增损失）

`label/jumpLabel`（幕内任意跳）、复合条件（`&&/||/函数`）、`branch` 内嵌块、
小游戏/特殊命令（`threeChooseOne` 等）、`unlockCg/unlockBgm`、`setTextbox`、
变量求值模拟（A6）。导入报告 warnings 逐条现有格式不变。

### 4.4 往返验收

`export(proj) → import_project_dir → export(again)`：两次导出目录**逐文件
逐字节一致**（伪幕命名纯函数保证），无 choice 工程与现状单文件路径全等。

## 5. DSH 命令面（④，与 run_command 风格一致，全部主线程）

| 命令 | args → data |

  文本 / 目标幕下拉 / set 表达式文本框 / when 文本框，上限内增删排序）；

  push_history 复用。
- **jumps/vars**：F1 底部两个可折叠列表（jump 行同"台词行"样式带条件列；

- **预览**：播放头到达 choice.t → 暂停 + 预览区弹选项按钮行（点击 = 切到目标

## 8. WebGAL 语法核对清单（对照 runtime js/官方文档）

1. `choose` 精确格式 ——**已核（2026-11-14，runtime 4.6.6 引擎 js + 官方
   demo）**：`choose:文本1:目标1|文本2:目标2;`；目标带 `.txt` = 跨 scene
   文件（demo：`choose:简体中文:demo_zh_cn.txt|…`），不带 = 同文件 label
   跳转。选项内文本转义 `：`→`\:`、`,`→`\,`、`.`→`\.`（demo_escape 实测）。
   选项数上限未发现引擎硬限（我方 6 上限自设）。
2. `jumpIf` ——**已核：不存在**。条件跳转命令是 `if`（引擎枚举 e.if=18），
   格式 `if:表达式:scene;`；`branch` 命令同样不存在（旧任务书/传闻语法）。
   表达式求值在运行时（demo 见 `$var + 5` 形态）。
3. 选项条件（`-when` 类）——**未证实**：引擎枚举与 demo 均未见选项级
   条件；L2 首日按官方文档终裁，不支持则走伪幕内 `if:` + 兜底目标。
4. `setVar` ——**已核**：`setVar:名=表达式;`，带 `-global` 选项（跨 scene
   持久，demo_changeConfig 实测），变量引用 `$name`。"入口初始化不被
   后续幕重置"→ 初始化只写 start.txt 头部 + 非 global 默认作用域实测。
5. `changeScene` vs `callScene` ——**已核**：两者都在枚举；**无
   returnScene 命令**，但引擎有 `sceneStack`（callScene 压栈、子 scene
   自然结束自动返回）。编辑器仍按 A4 放弃返回语义（表达成本高）。
6. scene 文件名规则（中文/安全化后加载实测）——**待 L2 首日**（导出
   安全化名 + http 加载验证）。
7. start.txt 纯跳转壳可行性 ——**待 L2 首日**（若首幕=start 方案与引擎
   入口约定冲突，改跳转壳 + 全幕独立文件名）。

## 9. 风险与边界

- **范围蔓延**：变量求值/存档编辑/小游戏命令明确不进 v3.5（§4.3 是硬边界）。
- 伪幕文件数量：每带 set 的选项 +1 小文件——典型 10 分支作 ×2 ≈ +20 文件，
  可接受；伪幕在编辑器**不作为幕出现**（只在导出目录）。
- 幕名安全化撞名复用 `_NamePool`；tab 显示名与 scene 文件名解耦（前者任意，
  后者安全化）。
- F1/workbench 是他人地盘：L5 单独成卡、依赖收敛在最后，冲突面最小。
